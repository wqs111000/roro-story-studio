# Codex 内部审核清单

## 内容

- [ ] 适合 4 周岁儿童理解，朗读约 3-6 分钟。
- [ ] 只有一个主要问题和一个主要成长主题。
- [ ] 没有把虚构事件写成佑佑的真实经历。
- [ ] Roro 是伙伴，不替代家长、不训斥孩子。
- [ ] 没有羞辱、贴标签、过度惊吓或要求保密。
- [ ] 动物或恐龙没有因为物种和外貌被默认善恶化。
- [ ] 教育内容自然进入情节，没有生硬测验。
- [ ] 简介、正文和可听旁白只讲故事；角色形态名、版本号、图鉴名和制作术语只留在视觉制作层，除非形态变化本身是已确认剧情。
- [ ] 每句对话在页面文字中有说话者，在最终音频中也能自然听出说话者；不能只朗读冒号后的台词。
- [ ] 每个候选音色都有独立的逐页时间轴，页码完整、起止时间单调且不超出对应音轨；切换音色不复用比例估算。
- [ ] 每个候选音色先在封面朗读一次 `《绘本标题》。`，封面标题片段结束并短暂停顿后才进入第 1 页正文。

## 原创和版权

- [ ] 没有复刻受保护角色、台词、世界观或标志性桥段。
- [ ] 没有模仿仍在世插画家的独特画风。
- [ ] 若使用第三方素材，来源和权利状态已经记录。

## 画面与音频

- [ ] 本故事已有代表性页面作为角色尺度锚点，并记录主要角色的相对大小。
- [ ] 同一故事中，角色处于近似景深和姿态时相对大小逐页一致；透视或动作造成的变化能够从画面解释。
- [ ] 没有因为另一故事采用不同相对尺度而误判本故事；跨故事尺度仅作宽松参考。
- [ ] 没有异常肢体、陌生角色或错误文字。
- [ ] 每个重复场地已有场景锚点；同一地点内剧情未改变的道路、建筑、树木、门窗、家具和道具关系前后一致；剧情换场或状态变化不作为漂移拒绝。
- [ ] 时间、天气、灯光、收纳或物件状态只按剧情明确变化，没有无解释的场景重排。
- [ ] 已查看整本联系表；仅对标记问题页查看原尺寸，未变化图片复用已绑定摘要的结论。
- [ ] 新制插图的原有 storyboard.json 已补齐共享视觉设定及逐页状态；逐页实际附带了清单中的图鉴和场景参考，旧分镜中的冲突描述已消除。
- [ ] visual-review.json 包含封面及全部页面的图片摘要、输入摘要、看图结论、理由和迭代次数；打包没有自动编造通过记录。
- [ ] 母版插图是全画幅场景，四边自然延伸；没有浅黄/米白底栏、字幕条、空白文字区、边框或排版占位。
- [ ] 画面下方约四分之一仍有连续的场景内容，没有突然淡出或纹理中断。
- [ ] 正文只出现在播放器或 PDF 排版层，没有重复占用图内预留区。
- [ ] 每页已记录 `accept`、`text-adapt` 或 `repair`；没有对未变化图片重复做理解审核，也没有无目标地连续生成近似版本。
- [ ] 若用文本适配好图，差异仅涉及非关键动作、道具、数量、表情或环境细节；主旨、因果、角色身份、安全边界和跨页逻辑未被改变，全部文本源与受影响页音频已同步。
- [ ] 音频真实存在、可播放，情绪和语速适合睡前。
- [ ] 内部已检查 TTS 控制标签、长静音和 ASR 内容，但这些实现细节不作为家长工作台审核条目展示。

## 内部制作门禁

- [ ] A：故事文本、年龄适配和方向。
- [ ] B：角色设定、Roro 形态和连续性参考。
- [ ] C：无字封面、代表性全画幅内页、故事尺度锚点和场景锚点。
- [ ] D：整本内页总览、疑点页原图、既有看图记录和最终主音轨。
- [ ] 已生成明确的 `candidate-manifest.json`、文件哈希与包摘要。
- [ ] `ai-review.json` 绑定当前候选摘要，结论为 `passed`。

以上由 Codex 连续完成。任何一项未通过时自行返修，不把未完成候选送入家长工作台。

`ai-review.json` 中技术性检查统一标记 `audience: internal`；工作台只显示面向家长的摘要和非内部检查。

## 工作台最终决定

- 模式：开发期免验证 / 家长 PIN 验证
- 状态：等待工作台确认 / 退回修改 / 已通过并上架
- 候选版本与包摘要：
- 问题标签与意见：
- 决定日期：

只有工作台将“通过并上架”持久绑定到当前候选版本和包摘要后，才能发布为不可变 `approved/` release。开发期动作必须记录为未验证身份的本地操作；PDF 与外部导出仍需另行请求。
