# Changelog

All notable changes are recorded here. This project follows semantic versioning.

## 0.1.0 - 2026-09-12

- First public-ready source release of the local-first Story Studio workflow.
- Added a reproducible CI verification workflow and declared runtime dependencies.
- Made local-only binding the default for native and Docker startup; LAN access is explicit.
- Documented the privacy boundary: family content stays ignored, while only the two README example images are explicitly redistributable.
