# 绘本工作台信息架构

## 备选故事来源与补充策略

可由另行配置的客户端定时任务读取 `inbox/story-generation-policy.json` 中的 `minimum_candidate_count` 并补足差额。当前网页服务自身没有每日创作调度器；策略文件存在不代表定时任务已启用。实际任务和数量需在执行时核对。

日常改编必须以 `inbox/daily-life/` 中家长提供的真实素材为输入。没有新素材时不虚构佑佑的生活，而改用原创冒险或通用母题再创作。新故事完整生成并通过内部检查后才进入备选故事库，不会自动加入制作或上架。

工作台按备选、制作中、待审核、已上架、已下架组织内容，垃圾桶位于备选区域。候选制作状态和已发布版本的书架状态独立：已有书架版本的故事可以同时有新版待审核。

| 区域 | 进入条件 | 主要动作 |
| --- | --- | --- |
| 备选故事 | 已有完整 6 页正文，尚未加入制作，也未丢弃 | 查看故事、加入制作、丢弃 |
| 制作进度 | 已加入制作，正在生成或返修图文、旁白和候选包 | 查看进度、预览已有候选 |
| 最终审核 | 图文、旁白、候选清单和质量检查均完成 | 逐页查看、试听、退回修改、通过并上架 |
| 已上架 | 已发布为本地不可变版本，且书架状态为 `published` | 查看版本、在书架打开、下架 |
| 已下架 | 已发布版本但书架状态为 `unpublished` | 查看下架原因、重新上架；不删除历史版本或制作中的候选 |
| 垃圾桶（备选故事内） | 从备选库临时移出的故事；只保留最近 6 个 | 查看故事、恢复备选 |

## 状态规则

1. “加入制作”在服务保存成功后写入制作清单，故事随即离开备选库并进入制作进度；不会自动生图或配音，后续由创作客户端执行 [制作管线](PRODUCTION_PIPELINE.md)。
2. 只有制作清单中的故事才会以 `authoring` 状态显示在制作进度；历史上已经产生制作资产或审核状态的故事视为已经开始制作。
3. `ready_for_parent` 只进入最终审核，不再同时出现在制作进度。
4. “查看进度”只用于检查资产完成度，不提供上架决定；“最终审核”才允许退回或通过上架。
5. 丢弃是备选故事内的可恢复状态，不删除 `drafts/` 内容；垃圾桶只展示最近 6 个，更早记录不再展示，也不会重新回到备选列表。
6. 下架只写入 `service/.runtime/shelf-status.json`（NAS/Docker 环境为 `/runtime/shelf-status.json`）并追加 `shelf-history.jsonl`；操作必须绑定当前 `release_id`，因此旧页面不能覆盖新书架版本。
7. 书架接口只返回 `published` 状态的发布版本；下架不会删除 `approved/<story-id>/releases/` 中的不可变发布目录。

## 阶段验收

- 备选库中看不到已加入或已丢弃的故事。
- 制作进度中看不到未加入、等待最终审核或已上架的故事。
- 最终审核只包含 `ready_for_parent` 候选。
- 页面上不使用“审核”指代普通制作进度查看。

## 书架分享

在书架卡片点击“分享”，选择 7 天、30 天或永久有效，再生成链接。PIN 模式需要验证身份；开发模式沿用当前免 PIN 会话。创建和撤销请求仍要求同源与 CSRF 校验。

链接绑定创建时的发布版本和内容摘要。撤销、过期、下架或切换发布版本后，分享入口失效；重新上架同一版本后，未撤销且未过期的链接可再次使用。原始令牌只在创建响应中返回，服务端保存 SHA-256 摘要，后续列表只能查看状态和撤销。

分享依赖接收方能访问同一家庭服务。当前书架、媒体和 PDF 入口保持开放，分享链接不是访问隔离或防下载机制；已有文件副本不能通过撤销收回。不要因新增分享功能而将服务开放到公网，具体边界见 [安全策略](../SECURITY.md)。

## 列表加载与缓存

备选入口先加载列表，再补充制作进度；直接进入制作或审核标签时优先加载制作目录。点击“查看”按需读取完整详情，并防止较早的请求覆盖后来打开的故事。制作清单和丢弃操作保存成功后立即反馈，列表在后台刷新；刷新失败会保留提示，写操作前重新核对会话状态。

PDF 排版缓存版本已更新为 7，结束页增加 `roro.iepose.cn` 署名。重新请求派生 PDF 时按新排版缓存生成，历史发布资产不原地修改。

- 目录结果在进程内缓存 8 秒，缓存时间从扫描结束开始计时。工作台写操作成功后清除相关缓存；直接修改磁盘文件后最多等待一个缓存周期。
- 备选列表只返回摘要，点击“查看”时通过 `/api/studio/story-library/<id>` 加载正文、对白和实际朗读稿。
- 工作台卡片使用最长边 480 像素的 WebP 缩略图；审核与播放器仍使用原图。缩略图位于运行目录的 `thumbnail-cache/`，Docker 使用 `/runtime`，本机使用 `service/.runtime`。
- 图片 URL 带修改时间和大小组成的版本标记；匹配版本的资源使用长期缓存。更新素材需更新文件修改时间。缩略图为可重建缓存，不属于发布资产。
