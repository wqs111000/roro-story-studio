# 制作流程与网页服务梳理（2026-09-05）

## 当前流程

家长提供想法或真实日常 → 创作客户端写封面加 6 页正文 → 网页选择加入制作 → 客户端在原有分镜中统一角色与场景设定 → 插图与旁白 → 内部看图/试听 → 绑定候选版本 → 工作台逐页审核 → 明确通过后本地上架。退回意见进入新候选，旧发布版本保留。外部导出另行决定。

网页是选择、进度、预览和审核入口；加入制作清单不会启动一个后台生成服务。创作由客户端继续执行。故事素材默认留在本地。

## 本轮改动

- 后续生成在原有分镜、插图和审核步骤中采用[补充视觉规则](../universe/visual-bible.md)：角色参考贯穿全书，场景只固定剧情未改变的部分。场景变化正常建立新锚点。
- 增加提示词与参考图清单编译、参考摘要验证、逐页视觉记录校验。新候选打包需真实审核证据，不能自动填入“通过”。
- 工作台增加折叠式流程指引、刷新进度、超时提示和制作下一步说明；加入制作在服务确认前不从列表消失。
- 修复已上架/已下架搜索、空列表初始化循环、上架失败重试被覆盖，以及导航时批量通过按钮残留。

## 信息与状态边界

| 对象 | 含义 |
|---|---|
| 备选 | 已有正文，可以选择制作 |
| 制作中 | 清单已选择或正在返修；素材齐全不等于视觉通过 |
| 待审核 | 当前候选与内部审核绑定，等待明确决定 |
| 已上架 | 本地不可变发布版本，播放器读取当前发布指针 |
| 已下架 | 暂时从书架隐藏，历史版本仍保留 |

现有书籍不在本轮更新范围，不修改图片、音频、候选审核或发布指针。工具校验记录和文件绑定，不自动判断画面语义。

## 验收范围与后续

自动回归覆盖网页服务、候选流程与新增视觉清单校验；浏览器核对实际加载、搜索及刷新。NAS 另有正在进行的工作区改动，其打包回归结果需单独报告，不能把本轮网页修改视为 NAS 部署完成。

本轮最终结果：83 项自动测试全部通过；实际浏览器确认已上架搜索能显示无匹配状态、导航不再残留批量通过按钮，390 像素宽页面无整体横向溢出，视图标签横向滚动。未对真实故事执行审核、上架或下架操作。

下一本新书应记录首轮通过页数、返修次数、缺陷类型与总耗时，完成整本视觉验收后才能判断一致性改善幅度。本轮未制作对照样本，不能宣称已经达到最终成图质量目标。

工作台 HTML 已同步到当前本地容器，不需要重启服务；源码保留于 service/ui/workbench.html。容器重建时须使用本工作区源码，旧镜像重建不会保留仅存在于容器中的文件。
